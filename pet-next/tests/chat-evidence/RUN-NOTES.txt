二、fake server 协议（已同步全队）
------------------------------------------------
POST {base}/（或任意非 /__* 路径）body {"id","text"}
  ok 模式:   200 {"id":<同请求>,"text":"演示回复：已收到「<原文>」"}
  error 模式: 可编程状态码（默认 500）{"id":...,"error":"fake-server-error"}
GET /__health | POST /__config {"mode","status","delayMs"} | POST /__reset | GET /__state
行为要点：
- 每请求的行为参数在收到时快照，之后的 /__config 不影响在途请求；
- 客户端断开不中断处理：延迟到期仍产出响应（respondedAt 晚于 closedAt 可证），送达失败如实记录；
  E2E 借此证明"旧请求迟到响应即使产出也不得上屏"。
